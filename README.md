Monocrawl provides a unified REST API that aggregates public social, search and e-commerce data from over 70 platforms, including TikTok, Reddit, YouTube, Instagram, X, LinkedIn, Google, Amazon, eBay, Airbnb and more. It enables developers and AI agents to retrieve posts, products, reviews, profiles, and other public content through a single key and unified schema, supporting use cases like brand monitoring, competitor tracking, review analysis, and AI-driven insights. The service offers free starter credits and tiered pricing for scaling usage.

**Areas:** Company · Data · Social Media · E-Commerce

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Monocrawl: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
